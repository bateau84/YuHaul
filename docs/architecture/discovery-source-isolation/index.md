# Discovery source isolation

- [ARD-001 — Isolate Uploads-Source Failures Within a Production Run](design/ard-001-isolate-uploads-source-failures.md) — Proposed full design for Run 52's failure mode. Commits observations before later requests can erase them, fences the retry watermark, and projects permanent source errors read-only in Errors. An all-local-failure scan ends Failed with explicit no-coverage evidence. Reconciled 2026-11-22 to build on ARS-002 (`030`) and `031` receipts.
- [ARS-001 — Durable Discovery Page Handoff](specifications/ars-001-durable-discovery-page-handoff.md) — Proposed. Exact page ownership, metadata readiness, deferred release and receiving-run contract, with restart proof. Reconciled 2026-11-22: §1.1 owners of every stored fact, §1.2 the run dispatch stop (`run.dispatch_stop`), §1.3 sealed scope and a derived acquisition state with no second assessment, §4.1 migration content against `031`, §7 open decisions.
- [ARS-002 — Durable Uploads-Source Failure Record and Read-Only Errors Projection](specifications/ars-002-durable-source-failure-record.md) — Migration `030` immutable `discovery_source_failure` table, written at the isolated failure before the next request; same-run resume skip; no clearing after later success; `GET /api/errors/sources` and `GET /api/runs/{id}/discovery-source-errors` with channel identity and vetted reason; read-only. Central migration allocation (`030` ahead of receipt; later numbers assigned at integration without gaps). Closes ADR-001 G1. §4.5 (2026-11-20) adds the run's `discovery_scan_outcome` for the scan-cut-short wording. §1–§4.4 are implemented in `5f849ea`/`1a0bf19` and §4.5 in `f88ada9`, shipped in PR #4 (`eed90f1`).
- [ADR-001 — Interim Channel-Granular Isolation of Unavailable Uploads Sources](decisions/adr-001-interim-channel-granular-uploads-isolation.md) — No-migration interim: skip a channel on exact `404 playlistNotFound`, keep completed channels and floors, ledger-derived incomplete note, explicit AC8 failure. G2 and G3 accepted, G1 closed by ARS-002; D6 withdrawn.
