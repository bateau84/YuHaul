# Architecture

- [YuHaul System Architecture](yuhaul-system-architecture.md) - Compliance-aware system architecture for YuHaul — two-store data model, processing pipeline, quota management, duplicate detection, and deployment model. Updated 2026-09-15 with fresh obligation mapping against 32 BRs + 3 OCs, reconciled outcome model with distinct "excluded" category per OC-002, and a five-phase pipeline (Discovery → Duplicate Detection → Exclusion → Routing → Action Execution) with a separated exclusion gate.
- [YouTube API Compliance Analysis](yuhaul-youtube-compliance.md) - Analysis of YouTube Developer Policies data-retention requirements and their impact on YuHaul's storage model.
- [ADR-001 — YouTube Provider Seam via Base URL Override](adr-001-youtube-provider-seam.md) - Threads `youtube.WithBaseURL` through the shipped binary behind `YUHAUL_YOUTUBE_BASE_URL` so Product Acceptance can run against a fake YouTube without modifying the binary.
- [ADR-002 — Failed-Phase Runs Terminate as `failed`, Not `completed`](adr-002-run-status-failed-terminal-state.md) - Adds `failed` as a fourth terminal Run status so phase failures and panics are not reported `completed`.
- [ADR-003 — Route Deletion Is a Soft Delete That Preserves Historical Decision Evidence](adr-003-route-soft-delete-preserve-history.md) - Soft-deletes routes via `deleted_at` so `route_decision`/`condition_audit`/`executed_action` and historical statistics survive deletion (BR-003 AC4, AC15/25/28).
- [ADR-004 — Canonical Condition Operator Vocabulary Is the Accepted Design Spec](adr-004-condition-operator-vocabulary.md) - Realizes the accepted spec's operators (`starts_with`/`ends_with`/`matches_regex`/`greater_than`/`less_than`/`between`) as the engine's single canonical set, retiring the drifted `gt/gte/lt/lte/not_*`/`in_list` vocabulary.
- [ADR-005 — `GET /api/playlists` Endpoint for the Action Playlist Picker](adr-005-playlist-listing-endpoint.md) - Adds a `playlists.list`-backed `GET /api/playlists` behind a `PlaylistProvider` seam so the Route Editor's action config can offer a real playlist dropdown.
- [ADR-006 — Route List Match Count Is Derived from route_decision, Not Materialized on the Route Row](adr-006-route-list-match-count.md) - Derives the Route List "match count" column from production-run (`scheduled`/`manual`) `route_decision` rows instead of a materialized counter, so the statistic cannot drift from decision evidence (resolves reviewer MAJOR-6).
