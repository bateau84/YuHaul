# Design

- [Admin interface design](yuhaul-admin-ui-design.md) — includes automatic account access renewal and safe recovery (US-001/SC-007; expiry alone is not reconnect-required), current/local run-video recognition and explicit unavailable context (not historical input; generic exclusions remain incomplete), Run Now recorded progress/closure (unknown discovery counts, saved phase/status, stale recovery, quota distinction), fixed duplicate-continuation Settings copy, recorded-history labeling, mode-aware simulation inspection labels/badge interpretation, and state-aware empty simulation copy (completed dry-run zero selection versus unknown, loading, running and failed states); US-011/US-012 earlier same-YuHaul production-outcome comparison remains accepted future-target design deferred from first-use launch.
- The admin interface design also defines run/decision playlist confirmation: authorization-pending work, unknown provider application, guard-only evidence, legacy unavailable details and safe account-status navigation without replay controls.
- The admin interface design defines causal exclusion attribution in run lists and decision detail, including permitted configured values and explicit incomplete legacy and unresolvable-reference states.
- The admin interface design defines Run Now resume after a time limit (BR-017 AC7–12): resumed-run acknowledgement, exact refusal copy for active-run, unresumable-run and unavailable cases, and the Run Detail interrupted-run explanation. Implemented in a016744; browser and screen-reader verification pending.
- The admin interface design also defines discarding a run that Run Now cannot resume (BR-017 AC13–21): the “Discard run {id}” control in the refusal and on Run Detail, its confirmation dialog, acknowledgement and refusals, and a naming rule that keeps it apart from the deferred queue's “Dismiss” button (renamed from “Discard”). Unfinished videos go to the deferred queue for the next run. Design only; not implemented.
- The admin interface design also defines compact one-line route results on the Run Detail video list (outcome plus short reason, with a Details disclosure for the full record) and the short comparison vocabulary used by them. Design only; not implemented.
- The admin interface design also defines marking a stuck legacy run as ended (BR-036): the “Mark run {id} as ended” control on Run Detail when `run.endable` is true, its confirmation, acknowledgement, refusals and final display, kept distinct from Stop and Discard. Implemented, review pending; browser and accessibility verification pending.
- The admin interface design also defines stopping an active run (BR-035): the “Stop run {id}” control for any active run including simulations, its confirmation, acknowledgement, “Stopping” state, “Stopped by user” final status and refusals. Design only; not implemented.
