## 2026-11-11

- Updated [admin interface design](/docs/design/yuhaul-admin-ui-design.md) after implementing “Mark a Legacy Run as Ended” ([ARS-004 §9](/docs/architecture/run-initiation/specifications/ars-004-mark-legacy-run-as-ended.md#9-implementation-record-and-deviations)). Set its status to implemented, browser and accessibility verification pending. Changed “Stop an Active Run” so Stop appears only when the run read says `executing` is true as well as `running`, because a stuck legacy run is saved as running but nothing executes it. No new copy.

- Amended [admin interface design](/docs/design/yuhaul-admin-ui-design.md), “Causal Exclusion — Run List and Decision Detail”, with “Compact route lines on the Run Detail list”, after a user report that route explanations took about eight lines each. The list now shows one line per route (label with short ID, short outcome, key reason), a short vocabulary for each exclusion type and condition operator, short truthfulness states, one list-level sentence about compared inputs, and a “Details” disclosure that holds the full route ID, configuration and exclusion number, comparison sentence and compared-input note. Decision Detail is unchanged. Updated three older sentences that required the full text on the list. Recorded gaps: the list read carries no failed-condition summary; the short route ID was kept and “needs …” used instead of “≠”; Specifier to confirm the compared-input wording against BR-015/OC-005. Design only; no code, browser or accessibility verification. Earlier uncommitted edits kept.
- Amended [admin interface design](/docs/design/yuhaul-admin-ui-design.md) with “Mark a Legacy Run as Ended” under [BR-036](/docs/requirements/yuhaul/br-036-mark-legacy-run-as-ended.md). Specified the “Mark run {id} as ended” control on Run Detail, driven by `run.endable`; the confirmation (marked failed, unfinished videos not processed); the acknowledgement; every refusal; and the Run Detail display of an ended run, with a comparison against Stop, Discard and a self-failed run. Added a rule to “Stop an Active Run” that a run with `endable` true shows no Stop control and does not hold Run Now unavailable, and changed the Discard acknowledgement's final status to “Run failed — discarded by user.”. Earlier uncommitted edits kept. Recorded gaps: no endpoint, codes or machine reason, and the 503 cause split. Design only; not implemented, no browser or accessibility verification.
