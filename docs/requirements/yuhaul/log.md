QS-001: with 150,000 known videos and 150,000 imported references, ID lookup ≤1 s and each name-search page ≤2 s at the 95th percentile, also during a production run. **Re-queue stranded videos (new BR-037); BR-036 amended; run 14 backlog decision superseded.** Source: the user's explicit approval of 2026-11-11, relayed in the specification assignment; the original human conversation was not independently inspected. A *stranded* video is known, not completed, has no committed outcome, has no active queue item, was not removed by the user, all its production runs have ended, and is not blocked. **Mark a stuck legacy run as ended (new BR-036).** Source: the user's explicit decision of 2026-11-11, relayed in the specification assignment; the original human conversation was not independently inspected. Added [BR-036](br-036-mark-legacy-run-as-ended.md), AC1–12. The user can mark an endable run as ended: a production run with mutation-safety version 0, status `running` or `interrupted`, not executing, while no production run is active, startup recovery is not running and shutdown has not begun. After a confirmation that names the run and says its unfinished videos will not be processed, the run becomes `failed` with a safe legacy reason such as "ended by user (legacy run)". Nothing else changes: no video, outcome, decision, action, guard or queue item, and no YouTube call. Its backlog stays unprocessed, consistent with the 2026-11-10 decision declining run 14 recovery; BR-036 is the deliberate exception to BR-035 AC16. Refusals cover version ≥1, simulations, terminal runs, executing runs, an active production run, startup recovery and shutdown. Repeats are idempotent and races follow one serial order. Run reads report an `endable` fact (the user's name), and the interface offers the action only where it is true. Specification choices, listed in BR-036: production runs only, because current simulations are also saved with version 0 (`internal/state/store.go:98–104`, evidence, not source); the "not executing" check; atomic save and recheck at execution; the ended run never blocks startup or later runs. [Index](index.md) summary, table and open questions are updated, and [run14-recovery](../run14-recovery/index.md) gets a pointer. Downstream: Architect and Designer. **Stop an active run (new BR-035) and discard to the deferred queue (BR-017 AC17).** Source: the user's explicit decisions of 2026-11-10, relayed in the specification assignment; the original human conversation was not independently inspected.

1. *New [BR-035](br-035-stop-active-run.md), AC1–21.* The user can stop any active run, after confirming. A stopped run ends as "stopped by user", not failed, and is never resumed. The stop makes no YouTube call, and the run starts no new request after the stop. A prepared, unsent addition has its guard released; an addition in flight is uncertain, keeps its guard and is never resent. An accepted stop survives a crash. Unfinished videos each get one pending, immediately eligible deferred item; a claimed Errors-queue entry moves to the deferred queue; removed stays removed; no claim is left behind. The next new run, manual or scheduled, claims and processes them although discovery does not report them as new, and an ended run never makes a later start fail. Covers startup recovery, shutdown, ended runs, double press and races. Simulations can be stopped, simply ended with no queue effects (the user's suggestion, adopted). Specification choices are listed in BR-035.
2. *Source check (the run 14 gap).* `internal/discovery/engine.go:327–333` skips known videos. `internal/queue/retry.go:463–469` and `:196–205` claim only deferred items with no waiting time left, or claimed by `failed` or nobody. `retry.go:258–289` with `internal/pipeline/pipeline.go:251–254` makes a whole run start fail on an item claimed by a run in any other ended state. `internal/pipeline/authority.go:357` sends uncovered unfinished videos to the Errors queue, which run starts never claim. BR-035 AC13–16 state the resulting obligations explicitly. This is evidence, not the source of meaning.
3. *[BR-017](br-017-manual-run-initiation.md) AC17 amended:* discard now hands unfinished videos to the deferred queue under BR-035 AC10–16, not to the Errors queue under ADR-006 §3. AC14, AC15, the example, AC10 (stopped runs excluded), Derived from, verification and dependencies are updated.
